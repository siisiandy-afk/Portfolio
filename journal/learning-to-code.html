Designing while learning to code

Design Development

The False Division

When beginners enter tech, they are frequently told to pick a track: either become a visual designer or become a back-end software engineer. But some of the most compelling products exist because their creators cared equally about how things work and how they feel.

Learning design principles—typography, spacing, hierarchy, and color theory—fundamentally changes the way you write code. You stop building generic interfaces and start engineering intentional, human-centered experiences.

Why Design Accelerates Development

Designing before coding forces clarity of thought. When you sketch user flows or mock up responsive screens in advance, you immediately expose logical bottlenecks and edge cases before writing a single line of JavaScript.

In tools like Fruit for Thought and the Church Quiz platform, taking time to design clear states (loading, error, interactive buzzer feedback) saved days of refactoring during the development phase.

Craft as a Discipline

Whether arranging genetic trait tables or polishing button hover states, attention to craft matters. Software is not merely functional; it is a creative medium for communicating ideas.
